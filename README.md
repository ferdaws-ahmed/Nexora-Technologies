# Xhoraa Technologies

Xhoraa → Xtreme Horizon Operations Research & AI Applications

A modern corporate website featuring AI/ML services showcase with stunning animations and responsive design.

## Tech Stack

- **Next.js 16.1.1** - React framework with App Router
- **React 19.2.3** - UI library
- **Tailwind CSS 4** - Styling
- **DaisyUI 5.5.14** - Component library
- **Framer Motion 12.31.1** - Animations
- **GSAP 3.14.2** - Motion platform
- **Swiper 12.0.3** - Slider framework
- **Lucide React** - Icons

## Features

- Animated hero section with full-screen slider
- Dark/Light theme switching
- Responsive design for all devices
- 6 core services showcase
- Interactive FAQ and contact forms
- Brand logo slider

## Pages

- Home - Hero slider, features, contact form, FAQ
- Services - 6 core services with details
- Projects - Portfolio showcase
- About Us - Company information
- Careers - Job listings
- Contact - Contact form and info
